# PR 编号：简短主题

## 状态与来源

- 上游、fork、PR：填写链接。
- 状态与检查时间：填写状态、日期和时区。
- 基线提交、修复提交、分支：填写 SHA 与分支名。
- 相关 issue、重复搜索、行为参考：填写链接或搜索范围。

## 问题与复现

说明触发条件、预期行为、实际行为和影响。记录正向对照、复现文件路径和执行命令；命令从对应源码 checkout 运行。

## 修复与回归覆盖

说明最终行为、关键实现和回归覆盖。补丁或源码使用固定提交链接，收录补丁时记录生成范围。

## 验证

| 环境 / 检查 | 结果 | 证据 |
| --- | --- | --- |
| 平台、JDK、定向测试 | 实际结果 | 摘要或链接 |
| 完整构建 | 通过 / 失败 / 未完成 / 未运行 | 摘要或链接 |
| 格式与差异检查 | 实际结果 | 命令或摘要 |
| 官方 CI | 检查时间及状态 | GitHub 链接 |

列明重试、排除、跳过、资源设置和未验证范围。一个分支的结果只适用于该分支的记录提交。

## 审核与后续

记录需要处理的审核意见、处理结果和最终合并链接。状态变化在本文件更新。
